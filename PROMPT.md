Build a static Astro site called SkipTheSub in this directory (/workspace/skipthesub). Use Astro (latest, npm), no UI framework, plain CSS. Requirements:
1. Data: create src/data/tools.json from SEED.md: one entry per paid tool (all 40 lines) with slug, name, alternatives[] {repo "owner/name", githubUrl, canDo:"TBD", cantDo:"TBD", minHardware {ramGB:"TBD", vramGB:"TBD", runsOn:[] }, setupDifficulty:"TBD"}. NEVER invent prices, costs, hardware, or capabilities: use the literal string "TBD". Paid tool monthly price: "TBD".
2. scripts/refresh-freshness.mjs: Node script that calls https://api.github.com/repos/{repo} for every unique repo (use GITHUB_TOKEN env if set), and writes src/data/freshness.json {repo: {stars, pushedAt, archived, latestRelease (from /releases/latest, null on 404), fetchedAt}}. Handle errors gracefully, keep old values on failure.
3. Pages: index (list of all 40 tools, search box, a 'Runs on my machine' filter with options Mac 16GB, GPU 8GB, GPU 12GB, GPU 24GB, CPU only; filter uses data-runs-on attributes and shows 'hardware data TBD' items under an 'Unverified' note), and src/pages/alternatives/[slug].astro per tool showing each alternative with GitHub link, canDo/cantDo, hardware, setup difficulty, and freshness (stars, last push, latest release, archived warning; if missing show 'not fetched yet').
4. A newsletter signup placeholder component (form with email input, action="#", note 'Newsletter coming soon', no external service).
5. A badge snippet on each tool page: copyable HTML <a href="https://skipthesub.pages.dev/alternatives/{slug}"><img src="https://skipthesub.pages.dev/badge.svg" alt="Listed on SkipTheSub"></a> and a public/badge.svg.
6. .github/workflows/refresh.yml: daily cron + workflow_dispatch, runs node scripts/refresh-freshness.mjs with GITHUB_TOKEN, commits freshness.json if changed (permissions: contents: write).
7. package.json scripts: dev, build, refresh. README.md with how to run and deploy to Cloudflare Pages (build cmd npm run build, output dist).
Then run npm install, node scripts/refresh-freshness.mjs, and npm run build, and fix errors until the build succeeds. Do not deploy, do not run git push, do not sign in to anything.
